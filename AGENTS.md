# AGENTS.md - Social Creator Workflow Governance

## 1. Project Overview
This project defines the enterprise-grade, end-to-end Content Creator Operating System (Social Creator Workflow). It unifies Chinese social platform intelligence gathering, strategic positioning, humanized multi-tier writing, industrial multimodal production, and asset compounding.

## 2. Universal Agent Standards
- Strictly follow the KISS principle and surgical edits.
- Zero emoji policy: Never generate emojis across all documentation, responses, and code.
- Chinese language for communication and thought processes; English for code comments.
- Respect local platform boundaries: use local native MCPs and certified tools over paid third-party scraping APIs.
